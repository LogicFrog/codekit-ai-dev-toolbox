# CodeKit 运行与部署说明

## 一、开发环境搭建

### 1.1 环境要求

| 组件 | 最低版本 | 说明 |
|------|----------|------|
| JDK | 21+ | 项目使用虚拟线程，必须 JDK 21 及以上 |
| Maven | 3.9+ | 构建管理 |
| MySQL | 8.0+ | 主数据库，需要 InnoDB 引擎 |
| Redis | 7.0+ | 搜索缓存（可选，不装也能运行但搜索无缓存加速） |
| Node.js | 20+ | 前端构建（仅开发前端时需要） |
| npm/pnpm | 最新 | 前端依赖管理 |

### 1.2 克隆项目

```bash
git clone https://github.com/LogicFrog/codekit-ai-dev-toolbox.git
cd codekit-ai-dev-toolbox
```

### 1.3 数据库初始化

确保 MySQL 服务已启动，创建数据库：

```sql
CREATE DATABASE IF NOT EXISTS codekit
    DEFAULT CHARACTER SET utf8mb4
    COLLATE utf8mb4_unicode_ci;
```

项目使用 JPA `ddl-auto: update`，首次启动会自动建表，无需手动执行 DDL。

### 1.4 后端配置

编辑 `src/main/resources/application-local.yml`：

```yaml
spring:
  datasource:
    username: root          # 你的 MySQL 用户名
    password: yourpassword  # 你的 MySQL 密码

codekit:
  watch:
    enabled: true
    path: /path/to/your/projects   # 需要扫描的代码目录
  fs:
    workspace-root: /path/to/your/projects

ai:
  provider: real
  model: your-model-id             # LLM 模型 ID
  base-url: https://ark.cn-beijing.volces.com/api/v3
  timeout: 120000
  max-tokens: 2048
  temperature: 1.0
  embedding-api: https://dashscope.aliyuncs.com/compatible-mode/v1/embeddings
  embedding-model: text-embedding-v4
```

**API Key 通过环境变量注入，不写在配置文件中：**

```bash
export CODEKIT_AI_API_KEY="your-llm-api-key"
export CODEKIT_AI_EMBEDDING_API_KEY="your-embedding-api-key"
```

如果嵌入 API Key 未单独配置，系统会自动复用 `CODEKIT_AI_API_KEY`。

### 1.5 启动后端

```bash
./mvnw spring-boot:run
```

启动成功日志：

```
Started CodekitApplication in X.XXX seconds
Tomcat started on port 8080 (http)
```

后端默认监听 8080 端口，Swagger API 文档访问 `http://localhost:8080/swagger-ui.html`。

### 1.6 前端开发（可选）

仅需开发/修改前端时执行：

```bash
cd web/codekit-client
npm install
npm run dev
```

前端开发服务器默认监听 5173 端口，API 请求会自动代理到后端 8080 端口。

## 二、生产/部署环境

### 2.1 打包后端

```bash
./mvnw clean package -DskipTests
```

产物位于 `target/codekit.jar`。

### 2.2 打包前端 Electron 桌面应用

```bash
cd web/codekit-client
npm install
npm run build:mac    # macOS
npm run build:win    # Windows
npm run build:linux  # Linux
```

产物位于 `web/codekit-client/dist-electron/`。

### 2.3 系统配置项速查

| 配置项 | 环境变量 | 默认值 | 说明 |
|--------|----------|--------|------|
| 数据库地址 | `CODEKIT_DB_URL` | `jdbc:mysql://localhost:3306/codekit` | 生产环境替换 |
| 数据库用户 | `CODEKIT_DB_USERNAME` | — | — |
| 数据库密码 | `CODEKIT_DB_PASSWORD` | — | — |
| Redis 地址 | `CODEKIT_REDIS_HOST` | `localhost` | — |
| Redis 端口 | `CODEKIT_REDIS_PORT` | `6379` | — |
| AI 提供商 | `CODEKIT_AI_PROVIDER` | `mock` | `real` 启用真实服务 |
| AI API Key | `CODEKIT_AI_API_KEY` | — | **必填**，启用 AI 功能 |
| AI 模型 | `CODEKIT_AI_MODEL` | — | LLM 模型 ID |
| AI 超时 | `CODEKIT_AI_TIMEOUT` | `30000` | 建议生产 120000 |
| 嵌入 API Key | `CODEKIT_AI_EMBEDDING_API_KEY` | 复用 `CODEKIT_AI_API_KEY` | 启用语义搜索 |
| 工作区路径 | `CODEKIT_WATCH_PATH` | — | 监听和扫描的根目录 |
| Spring Profile | `SPRING_PROFILES_ACTIVE` | `local` | 可选 `electron`（H2 模式） |

### 2.4 Electron 桌面模式（H2 数据库）

启动时设置 `SPRING_PROFILES_ACTIVE=electron`：

```bash
java -jar codekit.jar --spring.profiles.active=electron
```

此模式下数据库自动使用 H2 嵌入式引擎，文件存储在 `~/.codekit/data/codekit`，**无需安装 MySQL 和 Redis**。适用于个人桌面单机使用。

### 2.5 服务端口

| 服务 | 端口 | 说明 |
|------|------|------|
| 后端 API | 8080 | Spring Boot 内嵌 Tomcat |
| 前端 DevServer | 5173 | Vite（仅开发模式） |
| MySQL | 3306 | — |
| Redis | 6379 | — |

## 三、常见问题

**Q: 启动报 `Access denied for user`？**
A: 检查 `application-local.yml` 中的数据库用户名和密码是否正确。

**Q: AI 功能提示"未配置 API Key"？**
A: 确认已 `export CODEKIT_AI_API_KEY`，或在前端设置页面手动填入。

**Q: 语义搜索返回空结果？**
A: 检查 `code_embedding` 表是否有数据。如果没有，说明嵌入 API Key 未配置或嵌入 API 调用失败。配置 `CODEKIT_AI_EMBEDDING_API_KEY` 后触发重建索引即可。

**Q: 扫描大量文件时出现数据库连接超时？**
A: HikariCP 连接池默认 10 个连接，大量并发扫描时不够用。在配置中加 `spring.datasource.hikari.maximum-pool-size: 30`。

**Q: 全文搜索中文无效？**
A: MySQL 默认分词器不支持中文，需要用 `ngram` 解析器重建全文索引：

```sql
ALTER TABLE code_snippet DROP INDEX ft_combined;
ALTER TABLE code_snippet ADD FULLTEXT INDEX ft_combined (file_name, class_name, code_content) WITH PARSER ngram;
```

**Q: 怎样在无外部数据库的环境运行？**
A: 使用 `spring.profiles.active=electron` 启动，系统自动切换为 H2 嵌入式数据库，零依赖。
